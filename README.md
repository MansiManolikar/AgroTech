🌾 AgriTech Portal

AgriTech Portal is a smart agriculture management system developed using Flask, MySQL, MongoDB, HTML, CSS, and JavaScript. The platform helps farmers monitor weather and soil conditions, manage crops, and receive smart irrigation and farming recommendations through an easy-to-use dashboard.

🚀 Features

* Farmer & Operator Login
* Weather Monitoring
* Soil Moisture Tracking
* Smart Irrigation Suggestions
* Crop Management
* Notifications & Alerts
* Dashboard Analytics

🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Python, Flask
* Database: MySQL, MongoDB

▶️ Run Project

```bash
pip install -r requirements.txt
python app.py
```

This project aims to simplify farm management and support smart farming using modern web technologies and data-driven insights.
